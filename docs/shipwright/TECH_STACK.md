# Tech Stack: IBIS — Integrated Biodiversity Inventory Survey

## Platforms

- **Android and iOS** from one Flutter codebase (from PRODUCT.md Now — v1/MVP).
- **Server**: Linux host, self-hosted by a non-devops operator via Docker.

## Languages & runtimes

- **Dart 3.13** on **Flutter 3.47.5** (client).
- **TypeScript 7** on **Node 24 LTS** (server).
- **PostgreSQL 18** with **PostGIS** (latest 3.x built for PG 18) (server data).

## Frameworks & key libraries

### `app/` (Flutter client)

- **Flutter 3.47.5** — one UI codebase for Android and iOS.
- **flutter_riverpod 3.4** — state management and dependency injection.
- **drift 2.35** — offline SQLite store with forward-only migrations (ADR-0002).
- **flutter_map 8.3** + **latlong2 0.10** — map rendering over OpenStreetMap tiles, offline-friendly.
- **go_router 18.0** — navigation.
- **dio 5.11** — HTTP client for the REST API and the submission outbox.
- **uuid 4.6** — client-generated UUIDv7 identifiers.
- **sensors_plus 7.1** + **geolocator 14.1** — accelerometer/magnetometer/barometer and location.
- **record 7.1** + **image_picker 1.2** — audio and photo Evidence capture.
- **freezed 4.0** + **build_runner 2.16** — code generation for models and drift.

### `server/` (NestJS)

- **NestJS 12.1** (REST) — API framework (ADR-0005).
- **drizzle-orm 0.45** + **drizzle-kit 0.31** — data layer and forward-only migrations (ADR-0001).
- **pg 8.23** — PostgreSQL driver under Drizzle.
- **better-auth 1.7** — authentication on the Drizzle adapter (ADR-0003).
- **class-validator 0.15** + **class-transformer 0.5** — request validation (NestJS default).
- **@nestjs/swagger 12.0** — OpenAPI document for the client.

## Data layer

- **Server**: PostgreSQL 18 + PostGIS; Drizzle ORM 0.45; schema changes are forward-only SQL migrations generated by drizzle-kit 0.31.
- **Client**: SQLite via drift 2.35; forward-only, tested migrations.
- **Sync model**: no sync engine. In-progress Visits are device-only; submissions are immutable; corrections are append-only; ids are UUIDv7; an outbox uploads submissions and the client pulls project config, protocol, sites and target lists since a version token.

## Auth

**Better Auth 1.7** with the Drizzle adapter: email/password, optional
passkeys/OAuth. Auth only identifies a person; creator/collector/validator are
project-scoped Memberships in the domain (ADR-0003).

## Infrastructure & hosting

Self-hosted via **docker-compose**: API + PostgreSQL/PostGIS + media volume
(+ optional MinIO/S3). The server image is published to **GHCR**
(`ghcr.io/scerelli/ibis-server`) (ADR-0006).

## Third-party services

- **None required for v1.** OpenStreetMap public tiles by default; self-host tiles if the OSM usage policy is exceeded.
- **Optional S3-compatible storage** (MinIO or any S3) for media, off by default.

## Testing & tooling

### `app/` — Flutter / Dart

- test (all): `flutter test`
- test (one file): `flutter test test/<path>_test.dart`
- lint / analyze (check): `dart analyze`
- lint / analyze (fix): `dart fix --apply`
- format (fix): `dart format .`
- format (check): `dart format --output=none --set-exit-if-changed .`
- render proof: `flutter test test/goldens` (update: `flutter test --update-goldens test/goldens`; images under `app/test/goldens/`)

### `server/` — NestJS / TypeScript (pnpm 12.8)

- test (all): `pnpm exec vitest run`
- test (one file): `pnpm exec vitest run <path>`
- lint (fix): `pnpm exec eslint --fix <paths>`
- lint (check): `pnpm exec eslint <paths>`
- format (fix): `pnpm exec prettier --write <paths>`
- format (check): `pnpm exec prettier --check <paths>`
- typecheck: `pnpm exec tsc --noEmit`

### CI

GitHub Actions, one job per package running the check-only commands above.
**Dependency audit**: Dependabot (`.github/dependabot.yml`) plus a scheduled
`osv-scanner -r .` job (covers both Dart and npm).

## Tooling & CLI

- Scaffold the client: `flutter create --org <org> app`
- Add a client package: `flutter pub add <package>`
- Regenerate drift/freezed code: `dart run build_runner build --delete-conflicting-outputs`

## MCP servers

- **None installed.** Official MCP servers for Dart/Flutter, NestJS and Drizzle were not confirmed — the check relied on the GitHub API, which was rate-limited. Do not assume there is none; verify before adding a `.mcp.json` entry.

## Rejected alternatives

- **Server data layer** — PostgreSQL + PostGIS + Drizzle; Prisma (weaker PostGIS types), Kysely (no migrations/relations), Atlas/Flyway (second tool) lost (ADR-0001).
- **Client local store** — drift; sqflite (no type safety), raw sqlite3 FFI (most code), Hive/Isar (not relational SQL) lost (ADR-0002).
- **Auth** — Better Auth; Passport/JWT (own hardening), external OIDC (heavy for non-devops), hosted providers (break self-host) lost (ADR-0003).
- **Mobile framework** — Flutter; React Native (ruled out by the brief), native ×2 (double work), Kotlin Multiplatform (young iOS) lost (ADR-0004).
- **Server framework** — NestJS; Express/Fastify (less structure), a second language (solo dev), GraphQL (complexity) lost (ADR-0005).
- **Hosting** — Docker Compose + GHCR; Kubernetes, managed PaaS, per-OS installers lost (ADR-0006).
- **Media storage** — volume default + optional S3; S3-only and database blobs lost (ADR-0007).
- **Maps** — flutter_map + OSM; MapLibre (heavier), Google Maps (API key, conflicts with self-host) lost.
- **State management** — Riverpod; Bloc (boilerplate), Provider (scales worst) lost.
- **Server test runner** — Vitest; Jest (slower on TS), `node:test` (fewer features) lost.
- **Repo layout** — `app/` + `server/` + `packages/protocol/` + `infra/` (the shared protocol package is added by ARCHITECTURE.md); separate repositories (cross-repo overhead) lost.
- **Package manager** — pnpm; npm/yarn (slower, less strict) lost.

## Revisit triggers

- Media volume outgrows the host, or CDN delivery is needed → promote to S3/MinIO.
- OSM public tile usage policy is exceeded → self-host a tile server.
- Real-time multi-collector editing is required → add a sync engine.
- A required native capability has no adequate Flutter plugin → reconsider native.
- SSO or external-identity federation is required → external OIDC.
- Drizzle stalls or spatial requirements outgrow it → Prisma or raw SQL.
- Load or multi-node needs exceed one Compose host → revisit hosting.
